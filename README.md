## 👨‍💻 About Me

I am an **AI Engineer & Machine Learning Researcher** currently serving as a **Research Assistant** at the **Institute of Advanced Research (IAR)**, **United International University (UIU)**, Dhaka, Bangladesh, working under the mentorship and supervision of **[Prof. Dr. Hasin Anupama Azhari](https://ins.uiu.ac.bd/faculty/azhari-dr-hasin-anupama/)** (Dean, School of Science and Engineering; Director, Institute of Advanced Research).

My work focuses on bridging theoretical deep learning and practical production engineering — developing **safe and sustainable AI for healthcare**, **Agentic AI & stateful multi-agent systems**, **LLM/NLP orchestration**, **clinical cancer screening models**, **pediatric fracture segmentation**, and **real-world medical diagnostic applications** for hospitals and rural healthcare initiatives.

---

## 🔬 Research Focus & Core Areas

- **Safe & Sustainable AI for Healthcare:** Translating clinical AI models and survival translation architectures (COAST) from academic benchmarks to deployed production pipelines.
- **Medical Image Analysis & Radiomics:** Developing robust CNN/Transformer architectures for CT scan analysis, radiomic feature extraction, and survival modeling in oncology.
- **Pediatric & Adult Fracture Segmentation:** Unified multi-dataset training pipelines harmonizing adult (*FracAtlas*) and pediatric (*GRAZPEDWRI-DX*) domains.
- **Agentic AI & Stateful Multi-Agent Systems:** Designing LLM orchestration pipelines with cryptographic context validation to mitigate runtime prompt injection vulnerabilities.
- **Computer Vision & Bangla Sign Language (BDSL):** Developing multimodal finger-guided educational feedback systems (BanglaSign-Tutor) with Gemma 3 models.
- **Medical Physics & Rural Healthcare AI:** Field diagnostic tools, cancer screening logistics, and technical advocacy in collaboration with SCMPCR, AFOMP, and Alo Bhubon Trust.
- **Educational AI for Children:** Authoring child-friendly educational book series introducing foundational AI concepts to young learners.

## 🛠️ Architecture & Tech Stack

This website is engineered from scratch with performance, accessibility, and modern aesthetics in mind:

- **Core Frontend:** Semantic HTML5, Vanilla JavaScript (ES6+ modular pattern).
- **Design System:** Vanilla CSS3 with bespoke CSS Custom Properties, sleek dark mode by default, glassmorphism, fluid responsive typography, and WCAG AA contrast compliance.
- **Data Architecture:** Fully decoupled, JSON-driven content architecture (`assets/data/` for biography, research, experience, volunteering, projects, and contact info).
- **Search & Generative AI Optimization:**
  - **SEO:** Optimized meta descriptions, canonical URLs, and Open Graph / Twitter cards.
  - **AEO / GEO:** Advanced Answer Engine & Generative Engine Optimization directives tailored for AI search engines (Perplexity, ChatGPT, Gemini, Claude).
  - **Dublin Core & Schema.org JSON-LD:** Structured Person, ScholarlyArticle, ProfilePage, and Organization schemas.
- **Zero Framework Overhead:** Ultra-fast load times, zero build steps, 100% Core Web Vitals score, hosted on GitHub Pages.

## 🚀 Running Locally

To preview and run the website locally without any build tools:

### Option 1: Python HTTP Server (Recommended)
```bash
# Navigate to project root
cd saibhossain.github.io

# Start local server (Python 3)
python3 -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.

### Option 2: Node / npx serve
```bash
npx serve .
```

### Option 3: VS Code Live Server
Right-click `index.html` and select **"Open with Live Server"**.
